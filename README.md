# Matheus Henrique — Portfólio

Portfólio pessoal com projetos de aplicações web, automações com Python e produtos digitais.

## Abrir no computador

Abra `index.html` no navegador. Não precisa instalar dependências ou configurar banco de dados.

## Enviar ao GitHub

1. Crie um repositório chamado `portfolio` no seu GitHub.
2. Extraia este ZIP no computador.
3. Envie os arquivos extraídos ao repositório, mantendo `index.html` na raiz. Não envie apenas o ZIP.
4. Confirme o envio com um commit.

Para disponibilizar o site como página pública, configure GitHub Pages no repositório. Enviar os arquivos por si só não ativa a hospedagem.

## Conteúdo

- Apresentação e formação em Engenharia de Software online.
- Projetos VivaLeve IA, AgendaCerta, bot de atendimento e gerador de conteúdo social.
- Filtros por categoria e detalhes dos projetos.
- Áreas de atuação e link para o GitHub confirmado.

O estágio de cada projeto está descrito no próprio portfólio. As telas ilustrativas não são demonstrações funcionais das aplicações.
